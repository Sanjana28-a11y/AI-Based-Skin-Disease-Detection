# AI-Based Skin Disease Detection

An AI-powered web application that detects skin diseases from uploaded skin images using Deep Learning and Digital Image Processing techniques.

## Features
- Upload skin images
- AI-based disease prediction
- Confidence score display
- Image preprocessing using DIP
- User-friendly Flask dashboard
- Recommendations and precautions

## Technologies Used
- Python
- Flask
- TensorFlow / Keras
- CNN (Convolutional Neural Network)
- OpenCV
- HTML
- CSS
- JavaScript

## Digital Image Processing Techniques
- Image resizing
- Noise reduction
- Image normalization
- Feature extraction
## Output
The system predicts the skin disease from the uploaded image and displays:
- Disease name
- Confidence score
- Basic recommendations
